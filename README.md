# Yasmin Yusof — Portfolio Website

GitHub Pages project for https://myya-design.github.io/myyadesign/

## Upload
Upload **all files in this folder** to the root of the `myyadesign` repository. Do not upload the enclosing folder or ZIP. In GitHub Settings → Pages, select **Deploy from a branch**, `main`, `/(root)`.

## Editing
- `index.html`: page content, project cards, image URLs and metadata
- `styles.css`: colours, fonts, layout and animation styling
- `main.js`: navigation, filtering, lightbox and scroll animation
- `graduation-mascot.png`: hero mascot artwork

## Important
The supplied project references many portfolio images hosted on `mimottt.syamimi-sdin.workers.dev`. Only the two bundled project images have been switched to local files. To fully own the gallery, upload your own image assets and update their URLs in `index.html`. Do not rely on another person's server for long-term hosting. Replace sample projects, portraits and descriptions with your own work as appropriate.
