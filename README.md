# Portfolio — GitHub Pages ready (flat layout)

All website files are in the root directory. Upload **the contents of this ZIP** to the root of your GitHub `Portfolio` repository, not the ZIP itself.

1. Open the repository on GitHub and select **Add file → Upload files**.
2. Extract this ZIP first, then upload all extracted files together, including `index.html`, `styles.css`, `main.js`, and the image/font files.
3. Commit the changes. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Your site will be at `https://myya-design.github.io/Portfolio/` once deployed.

Note: The original HTML references many images hosted on an external website. Those images are not included in the supplied ZIP, so they still depend on that external host. Only the locally included images have been flattened. The Open Graph URL metadata may also need updating to your published domain.
